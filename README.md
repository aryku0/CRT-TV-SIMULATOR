# DVD Logo Satisfaction

A small Windows Avalonia app built with C# and .NET 10.

## Open It

Open `DvdLogoApp.slnx` in Visual Studio 2026, then run the app.

The app uses Avalonia UI for the desktop interface and NAudio for the bundled MP3 effects.

## Bundled Font

The app uses `DvdLogoApp/Assets/Fonts/Jost-500-Medium.otf`, a free Futura-like geometric sans font.

The Jost font license is included at `DvdLogoApp/Assets/Fonts/OFL-Jost.txt`.
